# Ritik Khare Portfolio

Open `index.html` in a browser to preview.

## Project manager
Click **Admin** in the navigation. You can:
- add projects
- edit projects
- hide/show projects
- delete projects
- export/import project data

Projects are stored in browser localStorage in this first version.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace LinkedIn/GitHub placeholder links.
3. Add real project/demo links.
4. Add a real resume PDF and change the hero button if desired.

For a production admin system accessible from multiple devices, connect the project manager to a database/authentication layer.
